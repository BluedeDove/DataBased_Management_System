# 数据库脚本清理计划

## 任务概述
清理项目中关于数据库数据生成的代码，并重新编写两个脚本：
1. 生成数据库虚假数据脚本（使用真实数据）
2. 删除数据库脚本（演示用）

## 现有代码分析

### 需要删除的文件
| 文件路径 | 说明 |
|---------|------|
| `scripts/generateTestData.ts` | 旧的数据生成脚本，混合了表结构创建和数据生成逻辑 |
| `scripts/generateTestData.js` | 编译后的JS文件 |

### 可保留的工具文件
| 文件路径 | 说明 |
|---------|------|
| `check_database.js` | 数据库检查工具，用于查看数据库内容 |
| `test_borrow.js` | 借阅功能测试工具 |

### 数据库表结构
系统包含以下8个表：
1. `users` - 用户表
2. `reader_categories` - 读者种类表
3. `readers` - 读者表
4. `book_categories` - 图书类别表
5. `books` - 图书表
6. `borrowing_records` - 借阅记录表
7. `role_permissions` - 角色权限表
8. `system_settings` - 系统设置表

## 新脚本设计

### 1. 数据生成脚本 (`scripts/generate-data.ts`)

**功能：**
- 仅生成测试数据，不创建表结构（表结构由应用启动时创建）
- 使用真实的中国图书数据
- 生成合理的读者和借阅记录

**生成数据量：**
- 图书：200本（使用真实图书信息）
- 读者：50个（学生、教师、职工）
- 借阅记录：150条

**真实图书数据来源：**
- 计算机科学类：经典技术书籍
- 文学类：中外名著
- 历史地理类：历史、地理书籍
- 数理科学类：数学、物理、化学教材
- 艺术类：艺术、设计类书籍

**默认账号：**
- 管理员：admin / admin123
- 图书管理员：librarian / lib123
- 教师：teacher001 / 123456
- 学生：student001 / 123456

### 2. 数据库删除脚本 (`scripts/clear-database.ts`)

**功能：**
- 删除所有表中的数据（保留表结构）
- 删除数据库文件（可选）

**选项：**
- `--data-only` - 仅删除数据，保留表结构
- `--all` - 删除整个数据库文件

## 实施步骤

### 步骤1：删除旧的数据生成代码文件
- 删除 `scripts/generateTestData.ts`
- 删除 `scripts/generateTestData.js`

### 步骤2：创建新的数据生成脚本
- 创建 `scripts/generate-data.ts`
- 实现真实图书数据生成逻辑
- 实现读者和借阅记录生成逻辑

### 步骤3：创建数据库删除脚本
- 创建 `scripts/clear-database.ts`
- 实现数据删除功能
- 实现数据库文件删除功能

### 步骤4：更新 package.json 脚本命令
```json
{
  "scripts": {
    "db:generate": "tsx scripts/generate-data.ts",
    "db:clear": "tsx scripts/clear-database.ts",
    "db:clear:all": "tsx scripts/clear-database.ts --all"
  }
}
```
